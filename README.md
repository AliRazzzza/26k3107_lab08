# InLab Tasks 08

## Task 1: ATM Management System

- Displays the balance and withdrawal limit
- Takes a withdrawal amount from the user
- Checks whether the withdrawal is valid
- Updates the balance after a successful withdrawal

## Task 2: Shopping Management System

- Offers five products to choose from
- Lets the user select items and enter quantities
- Allows repeated shopping and stores selected quantities in arrays
- Calculates the subtotal and applies a 10% discount on purchases of 5,000 or more
- Prints a receipt with the selected items and final bill
